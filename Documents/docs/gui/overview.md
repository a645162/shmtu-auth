# GUI 用户指南

shmtu-auth GUI 基于 PySide6 和 QFluentWidgets 开发，提供现代化的 Fluent Design 界面。

## 主要特性

- 🎨 **现代化界面** — Microsoft Fluent Design 设计语言
- 🌙 **多主题支持** — 浅色、深色和自动主题切换
- 📱 **系统托盘** — 最小化到托盘，不占用任务栏空间
- ⚡ **实时状态** — 实时显示网络认证状态和程序运行信息
- ⚙️ **可视化配置** — 图形化配置界面，无需手动编辑配置文件
- 🔄 **自动更新** — 支持检查和下载程序更新

## 启动 GUI

### Windows

```cmd
# 双击运行 GUI 版本
shmtu-auth-gui.exe

# 或命令行启动
python src/shmtu_auth/main_gui.py
```

### macOS

- 双击 `SHMTU Auth.app`
- 或从 Launchpad 启动

### Linux

```bash
python -m shmtu_auth.main_gui
```

## 界面布局

### 🏠 首页界面

首页是程序的主要控制面板，显示：

- **网络状态** — 当前网络连接状态（已认证/未认证）
- **认证状态** — 自动认证功能的运行状态
- **用户信息** — 当前配置的用户数量
- **运行时间** — 程序持续运行时间

快速操作按钮：开始监控 / 停止监控 / 立即认证 / 测试网络

### 📊 状态监控界面

- **实时状态** — 详细的网络连接信息
- **最后认证时间** — 上次成功认证的时间
- **认证次数统计** — 成功/失败次数统计
- **用户状态** — 每个用户的认证状态

### ⚙️ 设置界面

分为多个选项卡：

| 选项卡 | 功能 |
|--------|------|
| 用户配置 | 添加/删除用户、修改密码、设置密码加密 |
| 网络设置 | 检测间隔、重试设置、超时设置、User-Agent |
| 界面设置 | 主题选择、语言、开机自启动、托盘行为 |
| 通知设置 | 企业微信 WebHook、免打扰时间 |
| 高级设置 | 调试模式、日志级别、备份设置 |

### 📝 日志界面

- **实时日志** — 滚动显示最新的日志信息
- **日志级别过滤** — 按 DEBUG/INFO/WARNING/ERROR 过滤
- **关键字搜索** — 搜索特定的日志内容
- **导出日志** — 保存日志到文件

### ℹ️ 关于界面

- 程序版本、构建时间、开发者信息
- 开源许可证信息
- GitHub 仓库链接
- 更新检查

## 快捷键

| 快捷键 | 功能 |
|--------|------|
| `Ctrl+M` | 最小化到系统托盘 |
| `Ctrl+S` | 开始/停止监控 |
| `Ctrl+T` | 测试网络 |
| `Ctrl+L` | 打开日志界面 |
| `Ctrl+,` | 打开设置界面 |
| `Ctrl+Q` | 退出程序 |

## 系统集成

### 开机自启动

| 平台 | 方式 |
|------|------|
| Windows | 注册表启动项（`auto_start_windows.py`） |
| macOS | LaunchAgent plist（`auto_start_macos.py`） |

### 系统托盘行为

- **单击** — 显示/隐藏主窗口
- **双击** — 恢复主窗口并置于前台
- **右键** — 显示上下文菜单（开始/停止监控、检查更新、退出）

## 安装 GUI 依赖

```bash
pip install -e ".[gui]"
```

额外依赖：`PySide6`、`PySideSix-Frameless-Window`、`darkdetect`、`PySide6-Fluent-Widgets[full]`

## 已知限制

- **Windows AMD 显卡**：Mica 云母特效存在兼容问题，已全局关闭
- **macOS x64**：Python 版本必须 ≤ 3.11，否则无法安装 PySide6

## 性能参考

- **内存占用** — 通常 50-100MB
- **CPU 使用** — 空闲时 < 1%，检测时 < 5%
- **网络流量** — 每次检测约 1-2KB
