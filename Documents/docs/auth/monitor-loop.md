# 监控循环

shmtu-auth 的核心是一个后台监控线程，周期性检测网络状态并自动登录。

## 工作流程

```
启动监控线程
  │
  ├─ 读取用户列表
  │   ├─ 从环境变量解析学号与密码
  │   └─ 校验用户列表非空
  │
  └─ 进入监控循环 ─────────────────┐
       │                           │
       ├─ 检测网络状态              │
       │   ├─ 在线 → 等待下次检测   │
       │   └─ 离线 → 尝试登录       │
       │       │                    │
       │       ├─ 遍历用户列表       │
       │       │   逐一尝试登录      │
       │       │                    │
       │       ├─ 任一成功 → 记录    │
       │       └─ 全部失败 → 记录错误 │
       │                           │
       └─ 等待 time_interval 秒 ───┘
```

## 检测间隔

默认检测间隔为 **10 秒**。可通过环境变量覆盖：

```bash
# 设置检测间隔为 60 秒
export SHMTU_AUTH_TIME_INTERVAL=60
```

::: warning
间隔过短可能对校园网认证服务器造成压力，建议不低于 30 秒。服务器部署推荐 60 秒。
:::

## 多用户登录策略

配置多个学号时，程序按列表顺序逐一尝试登录，直到有一个成功：

```python
# user_list_3 格式: [(学号1, 密码1), (学号2, 密码2), ...]
net_auth.login_by_list(user_list_3)
```

1. 尝试学号 1 → 成功则停止
2. 学号 1 失败 → 尝试学号 2 → 成功则停止
3. 全部失败 → 等待下次循环重试

## 线程模型

监控循环运行在独立线程中，主线程不被阻塞：

```python
t = threading.Thread(target=monitor_auth)
t.start()
```

GUI 模式下，主线程负责 UI 渲染，监控线程负责网络操作。

## 日志输出

每次循环的关键事件均通过 loguru 记录：

- 网络状态检测结果（在线/离线）
- 登录尝试与结果
- 用户信息脱敏显示（如 `2025*****004`）

日志文件保存在 `logs/` 目录下，支持自动轮转。
